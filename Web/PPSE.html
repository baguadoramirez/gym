Estado: reposo
Cómo interactuar
  • Toca cualquier neurona para enviar un PPSE. Funciona con toques (tablets/móviles) y con teclas 1…0
  • Activa varias neuronas casi a la vez para ver sumación espacial.
  • Repite activaciones antes de que concluya un PPSE para ver sumación temporal.
  • Cuando aparece un potencial de acción, se muestra después un periodo refractario absoluto seguido de relativo.
  • Pulsa Capturar PNG o Descargar SVG para guardar el gráfico actual.

Potencial de membrana (mV)

Eje vertical fijo de −90 a +50 mV. Ventana temporal: 100 ms (alta resolución). El eje horizontal no muestra marcas.
